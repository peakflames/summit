## 1. System Overview

Summit is a single-page habit tracker: users add habits, mark them done for the day, track a
streak count per habit, and filter by active/archived status. It is a client-only SPA with no
backend — all state is persisted in the browser's `localStorage`. It is built as the public
reference example for the `peak-workflow` plugin.
